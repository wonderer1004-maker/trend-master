# V7 빠른 추세·변동성 조절 후보

목표는 V5_L50보다 높은 수익률과 낮은 최대낙폭입니다. 두 목표 달성은 결과로 확인하고, 실패한 경우 실패로 보고합니다. 앞선 결과를 본 뒤 후보를 추가했으며 이후 검사 기간을 반복 사용했으므로 과적합 위험이 높습니다. 미사용 검증으로 표현하지 않습니다.

## 시장 조건검색·매매
일반ETF(069500) 종가>20일선, 20일선>60일선, 종가>200일선.
세 조건이 3거래일 연속 충족해야 투자합니다. 조건이 깨지면 다음시가 현금100%. 다시 3거래일 확인 후 다음시가 재진입.
FAST100: 조건충족시 실제레버리지ETF(122630)100%, 비충족시 현금.
FAST45: FAST100의 최근60일 예상변동성이 연45%를 초과하면 비중축소, 남는금액 현금. 금요일 종가 비중갱신, 조건변경은 매일 대응.
MIX45: 조건충족시 레버리지ETF60%+상위2종목40%, 이후 동일한 연45%목표변동성 축소. 선정종목이 없으면 레버리지ETF100%를 기초비중으로 삼아 변동성축소 적용.
예상변동성은 공분산으로 계산하며 실현변동성·손실상한을 보장하지 않습니다.

## 종목 검색
종가>50일선>150일선, 60/120일 수익률 양수, 평균거래대금50억원 이상.
점수=20일수익률×0.2+60일×0.4+120일×0.4−시장ETF동일점수. 상위2개 균등배분. 1개뿐이면 그종목40%.
보유종목50일선이탈 또는 최고종가 대비12%하락 → 다음시가 재선정·청산, 20거래일 제외.
계좌고점대비25%하락 → 다음시가 청산·10거래일중단. 재개시 고점기준초기화. 누적MDD25%상한이 아니며 반복손실·갭으로 초과할수있습니다.
종가 확인→다음 시가 가상체결. 일중 실시간손절이 아닙니다.

## 선택·검증
2020~2023, 기본/비용2배의 낮은Calmar(CAGR/최대낙폭 절댓값) 최고후보 선택. 이후2024~2026.09는 결과확인에만 사용.
수익과낙폭이 모두V5보다개선되는지 비용별비교. 일반ETF매수보유도 비교.
기본연구비용은 수수료각0.05%+슬리피지각0.1%, 개별주매도세가정0.2%, 두ETF매도세가정0%. 계좌별소득세·레버리지ETF과표기준가·분배금세금은미반영. 세후수익률이 아닙니다.
Yahoo조정OHLC·현재생존대형주10개. 실제ETF가격사용. 전종목·상폐·기업행위독립검증미완료.
input/ 폴더에 사용한조정가격CSV스냅샷저장. 동일가격재실행은 --data-dir reports/trend_fast_v7/input.
