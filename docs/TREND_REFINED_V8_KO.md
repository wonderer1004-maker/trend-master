# V8 소폭 수익 개선·낙폭 감소 연구 후보

현재 가상운용 후보 DUAL_BAND45. 과거 자료에서 V7 MIX45 대비 수익률을 소폭 높이고 최대낙폭을 낮췄습니다. 실계좌 주문은 연결되어 있지 않으며 미래 성과는 검증되지 않았습니다.

## 바뀐 부분
1. 예상 포트폴리오 변동성을 최근20일과60일 공분산으로 각각 계산하고 더 큰 값을 사용합니다. 변동성 급증에 더 빨리 투자비중을 줄입니다.
2. 금요일 비중 조정 시 현재비중과 목표비중 차이가 모든 자산에서5%포인트 미만이면 매매하지 않습니다. 작은비중변경의 비용을 줄입니다. 시장신호변경·개별종목손절·계좌중단은 이매매완충보다 우선합니다.
위험축소량이5%포인트미만인주간목표변경도보류될수있으므로 목표변동성45%를항상유지한다는보장은없습니다.

## 진입·종목검색·매도
시장ETF(069500) 종가>20일선,20일선>60일선,종가>200일선. 3거래일연속충족후다음시가가상진입. 조건깨지면다음시가현금전환.
기초배분은 실제레버리지ETF(122630)60%+선정종목2개40%. 1개뿐이면그종목40%,없으면레버리지ETF100%를기초비중으로두고변동성축소.
종목종가>50일선>150일선,60/120일수익률양수,20일평균거래대금50억원이상.
순위점수=20일수익률×0.2+60일×0.4+120일×0.4−시장ETF동일점수.
투자비중축소계수=min(1,연45%/max(최근20일예상변동성,최근60일예상변동성)), 남는금액현금.
개별종목50일선이탈 또는 보유최고종가대비12%하락 → 다음시가청산·재선정,20거래일재선정제외.
계좌고점대비25%하락 → 다음시가청산·10거래일중단,재개시고점기준초기화. 반복손실·갭으로실제누적MDD는25%를넘을수있습니다.
