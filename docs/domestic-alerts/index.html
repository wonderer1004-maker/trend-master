사용 방법

① 보유·현금을 등록합니다. ② 알림을 허용합니다. ③ 매수/매도 후보를 확인하고 본인이 거래합니다.

야후 자료는 GitHub Actions로 평일 한국시간 16:20·17:20 갱신을 시도합니다. 실행 지연·조회 오류가 있을 수 있으므로 기준일을 확인하세요. 브라우저는 5분마다 게시 자료를 확인합니다.

장중 실시간 손절 알림이 아닙니다. 화면을 열어 둔 동안 조건 알림을 표시하며, 닫힌 앱의 스마트폰 푸시·문자 기능은 없습니다. 휴대폰은 브라우저에 따라 화면 내 알림만 지원할 수 있습니다.

최대 4종목, 종목 신규 비중 20%, 거래당 초기 위험 0.5%, 총 초기 위험 1.5%, 손절 2ATR, 최대 10거래일입니다. 계좌 위험은 수동 입력 잔고 기준입니다. 보유·현금 누락, 입출금, 수정주가에 따라 계산이 달라집니다.
