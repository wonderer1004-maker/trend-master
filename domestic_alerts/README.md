# 국내 ETF 야후 알림 웹앱

기존 국내 ETF 상대강도 전략을 휴대폰에서 볼 수 있는 GitHub Pages 웹앱으로 옮겼습니다. 증권사 주문은 전송하지 않습니다.

## 웹 주소
GitHub Pages 활성화/배포 성공 후:
https://wonderer1004-maker.github.io/trend-master/domestic-alerts/

## 최초 게시 설정
저장소 Settings → Pages → Build and deployment → Source에서 **GitHub Actions**를 선택합니다. 이후 Actions → **Domestic ETF Yahoo alerts** → Run workflow를 실행합니다. 이 설정은 저장소 관리자 권한이 필요합니다. workflow 파일만 추가하는 것으로 Pages가 처음 자동 활성화되지는 않습니다.

## 웹앱 사용
- 매수 후보, 손절가, 허용 매수가 상한, 참고 수량을 확인합니다.
- 실제 매수 후 종목·수량·매수가·초기 손절·매수일을 등록하고 실제 남은 현금을 저장합니다. 매도 후 해당 보유를 삭제하고 현금도 함께 갱신합니다.
- 보유 정보는 localStorage에만 저장합니다. 저장소/서버에 공개하지 않으며 다른 기기와 동기화하지 않습니다. 브라우저 데이터 삭제 시 보유·알림·위험 기준도 사라집니다.
- 브라우저 알림 허용을 누릅니다. 휴대폰에 따라 시스템 알림 대신 화면 기록만 지원합니다. 화면을 닫았을 때의 모바일 푸시는 구현하지 않았습니다.

## 전략
대상: KODEX 200, 코스닥150, 반도체, 은행, 자동차, 건설.
KODEX200 종가 > MA20 > MA60이면 BULL. 해당 ETF도 같은 정렬, 양수 20일 수익률, 20일 평균 거래대금 5억원 이상이면 순위를 계산합니다. 지수 역순은 BEAR, 나머지는 NEUTRAL입니다. BULL에서만 새 매수 후보를 만듭니다.

신호 종가에서 초기 손절 = 종가 - 2ATR, 매수 상한 = 종가 + 0.5ATR. 다음 거래일 시가가 손절 이하 또는 상한 초과이면 취소합니다. 시가 진입을 가정하므로 장중 등록 보유는 매수 전 당일 저가와 구별하지 못합니다.

초기 기준금 500만원, 거래당 초기 위험 0.5%, 전체 1.5%, 종목 신규 비중 20%, 그룹 40%, 최대 4종목, 전일 거래량 0.1%, 현금 한도. 표시 수량은 종가에 편도 슬리피지 0.10%를 더한 가격으로 계산한 참고값이며 수수료 편도 0.015%와 슬리피지 비용을 반영합니다. 실제 시가에 재계산해야 합니다. 계좌 금액에 따른 완전 자동 리밸런싱은 아닙니다.

등록 보유는 매수일부터 일봉 재생으로 손절, 초기 1R 상승 후 고가-2ATR 추적(다음 거래일부터 적용), 최대 10거래일, 시장 BEAR 청산을 계산합니다. 매도 확인이 필요하면 보유 삭제/현금 갱신까지 매수 후보를 보류합니다. 개인 등록 보유의 계산은 브라우저 logic.mjs에서 실행하며 서버의 Python 지표/매수 후보와 역할을 나눕니다. 임의로 손절을 낮추지 마십시오. 자료 수정이나 사용자 입력 변경 시 재생 결과가 달라질 수 있습니다.

현금과 보유 종가 평가액으로 일간 -2% 또는 고점 대비 -8% 위험 잠금을 계산합니다. 사용자 수동 입력 잔고에만 의존합니다. 앱을 오랫동안 열지 않으면 그 사이 매일의 계좌 손실은 관찰하지 못합니다. 입출금·보유 누락/입력 변경이 실제 손실과 다르게 인식될 수 있습니다. 기준 초기화는 원인 검토 후 직접 버튼을 눌러야 하며 자동 해제하지 않습니다.

## 데이터 갱신과 한계
GitHub Actions가 평일 한국시간 16:20와 17:20에 야후 chart 조회/검증/Pages 배포를 시도합니다. Actions 일정은 지연될 수 있습니다. Python 수집기는 16:10 이전 당일 봉을 제외합니다. 브라우저는 게시된 JSON을 5분마다 읽습니다. 직접 야후를 브라우저에서 호출하지 않아 CORS 프록시가 필요하지 않습니다.

조회 실패/ETF 날짜 불일치/잘못된 OHLCV/7일 초과 오래된 자료이면 빌드가 실패하고 새 배포를 하지 않습니다. 웹은 마지막 성공 데이터의 기준일을 계속 표시하며 7일을 초과하면 새로운 신호를 차단합니다. 7일 이내여도 최신 거래일 자료가 아닐 수 있으므로 화면 날짜를 확인해야 합니다. 장중 실시간 알림이 아닌 **확정 일봉 기반 사후 손절 확인·다음 거래일 후보**입니다. 이미 지난 신호일을 현재 거래 지시로 해석하지 마십시오.

원시 OHLC, ETF 분배금/수정주가 미처리, 비공식 chart 경로의 지연·차단·응답 변경 가능성이 있습니다. 미래 수익이나 실제 체결을 보장하지 않습니다.
