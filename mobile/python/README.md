# TREND MASTER 국내 단타 연구·자동 리플레이 V1

현재 상태: 실행 가능한 5분봉 백테스트/자동 페이퍼 리플레이와 키움 읽기 전용 데이터 수집 어댑터.
**실시간 증권사 자동주문 시스템은 완성되지 않았습니다. 실제 국내주식 수익률도 아직 검증되지 않았습니다.**
2020~2026 실제 분봉 데이터는 포함하지 않았습니다. 예제는 전부 합성 데이터입니다.
키움 어댑터는 자격증명 및 네트워크 제약으로 실제 API 연결 테스트를 하지 못했습니다.

## 설계
장기 전략을 분봉에 그대로 복제하지 않고 전일 추세와 당일 돌파를 분리합니다.
미너비니/와인스타인은 일봉 선별, 다바스/리버모어는 30분 박스 돌파,
터틀은 ATR 손절과 추적손절, 반 타프는 위험기준 수량 산정에 반영했습니다.
30주 Stage 2, VCP 자동인식, 펀더멘털 점수, 피라미딩은 이 버전에 구현하지 않았습니다.
RSI와 각 숫자는 검증할 연구 가설이며 최적값으로 확정한 값이 아닙니다.

| 단계 | 계산 규칙 |
|---|---|
| 전일 종목 선별 | 전일까지 종가 > MA50 > MA150 > MA200, MA200 > 20거래일 전 MA200, 종가 ≥ 252일 최고종가의 75% |
| 유동성 | 전일까지 20일 평균 종가×거래량 ≥ 50억원 |
| 시장 BULL | 당일 벤치마크 종가 > VWAP, EMA20 > EMA50 |
| 시장 BEAR | 두 조건 모두 반대 또는 지표/동시각 데이터 없음 |
| 시장 NEUTRAL | 나머지, 위험 절반·거래량 2배 이상 |
| 매수 신호 | 완성 5분봉 종가가 직전 6봉 고가를 상향 돌파, VWAP 위, EMA20 > EMA50, RSI14 55~75 |
| 거래량 | 현재 완성봉 거래량 / 직전 20봉 평균 ≥ 1.5 |
| 추격 제한 | 신호 종가가 피벗 + 0.5ATR 이하, 다음 봉 체결 추정가가 피벗 + 0.75ATR 이하 |
| 시각 | 신호봉 시작시각 09:30 이상 14:00 미만. 일중 지표 준비에 최소 30봉 필요하므로 실제 첫 신호는 11:25 이후 |
| 초기 손절 | 신호 종가 − 1.5ATR14. 체결가 대비 손절 거리 0.3~2%만 허용 |
| 크기 | 거래당 계좌 0.3% 위험, NEUTRAL 0.15%, 종목당 최대 20%, 동시 3종목 |
| 추가 제한 | 전봉 거래량의 1% 이내 수량, 종목별 하루 1회 진입, 신용·공매도 없음 |
| 일 손실 제한 | 청산비용 반영 평가자산이 당일 시작 대비 −1.5% 도달하면 신규 매수 중단, 다음 이용 가능한 봉 시가 청산 |
| 보유 | 당일까지 고가 − 2.5ATR로 손절 상향만 허용. 새 손절은 다음 봉부터 적용 |
| 청산 | 손절 또는 15:15 봉 시가. 오버나이트 금지 |

계좌 100만원이면 거래당 위험예산 3,000원, 종목당 최대 매수금액 20만원입니다.
갭·슬리피지로 실제 손실은 이 위험예산이나 일 손실 제한을 넘을 수 있습니다.
수익률 목표, 고정 익절, 물타기, 피라미딩은 사용하지 않습니다.

## 설치·한 번에 실행
Python 3.10 이상 PC에서 ZIP을 풀고 터미널로 이 폴더에 이동합니다.

```bash
python -m pip install -r requirements.txt
python -m unittest -v
python demo.py
python cli.py --bars data/synthetic_bars.csv --index data/synthetic_index.csv --daily data/synthetic_daily.csv --synthetic --out reports/demo_cli
```

`reports/synthetic_*`와 `reports/demo_cli`는 합성 데이터 테스트 결과이며 투자 수익률이 아닙니다.
리플레이 비교 결과가 같아도 시장필터 효과가 없다는 증거가 아닙니다.

## 실제 데이터 파일
동일 형식의 CSV 세 개가 필요합니다.

```csv
timestamp,symbol,open,high,low,close,volume
2026-10-07 09:00:00,005930,60000,60100,59900,60050,120000
```

- bars.csv: 선택한 국내 보통주의 실제 5분 OHLCV. 시간은 한국시간 **봉 시작시각**.
- index.csv: 동일 날짜·시각의 단일 시장 지수 또는 거래 가능한 시장 ETF 대용지표. ETF를 쓰면 지수 그 자체와 다릅니다.
- daily.csv: 각 종목의 일봉. 첫 평가일 이전 최소 252거래일의 준비기간 포함.
- 일봉 날짜는 해당 거래일, 가격/거래량은 숫자, 종목코드는 6자리 문자열.
- 기본 모드는 종목/날짜마다 09:00~15:15의 76개 봉을 요구하며 누락·단축장·거래정지는 거절합니다.
- 수집 API의 봉 시각이 시작인지 종료인지 반드시 대조 후 변환합니다. 진행중인 봉은 제거합니다.
- 키움 조정가격과 비조정가격을 혼용하지 않습니다. 미래 기업행사가 과거 가격·거래대금 선별에 영향을 주는지 검토해야 합니다.
- 관리/거래정지/우선주/스팩/ETF/ETN 등 제외는 **입력 유니버스 준비 단계에서 직접 처리**해야 합니다. 이 엔진에는 역사적 종목 마스터가 없습니다.
- 실제 전체시장 검증에는 상장폐지 종목과 당시 유니버스를 포함해야 합니다. 현재 종목만 사용하면 생존편향이 생깁니다.

```bash
python cli.py --bars data/bars.csv --index data/index.csv --daily data/daily.csv --out reports/actual
python compare.py --bars data/bars.csv --index data/index.csv --daily data/daily.csv
python paper.py --bars data/bars.csv --index data/index.csv --daily data/daily.csv
```

결과: summary.json(수익률·MDD·승률·PF·평균 R), trades.csv(체결내역), equity.csv(평가자산).
compare.py는 시장필터 제거, 슬리피지 2배, 매도세율 가정별 비교와 분기별 고정규칙 검증을 수행합니다.
분기 검증은 각각 초기자금으로 시작하며 학습/튜닝을 수행하지 않는 시간 분할 평가입니다.
이를 최적화 또는 정식 walk-forward 학습이라고 부르지 않습니다.
CAGR는 단기/불완전 데이터에서 오해를 피하기 위해 출력하지 않습니다.

## 키움 데이터 수집 준비
공식 안내: https://openapi.kiwoom.com/guide/apiguide
모의투자용 App Key와 App Secret을 발급하고 PC 환경변수에 설정합니다.
키는 소스·ZIP·GitHub·채팅에 넣지 않습니다.
이 어댑터는 모의 도메인 `https://mockapi.kiwoom.com`만 사용합니다.
OAuth /oauth2/token, 분봉 ka10080, 일봉 ka10081를 이용합니다.
현재 공식 명세와 본 어댑터 필드/응답 배열을 대조한 후 실행해야 합니다.

Windows PowerShell:
```powershell
$env:KIWOOM_APPKEY="본인의 모의투자 앱키"
$env:KIWOOM_SECRET="본인의 모의투자 시크릿"
python kiwoom.py --symbols 005930,000660 --kind minute --pages 30 --out data/raw_minutes.csv
python kiwoom.py --symbols 005930,000660 --kind daily --pages 10 --out data/daily.csv
python kiwoom.py --symbols 069500 --kind minute --pages 30 --out data/raw_index_proxy.csv
```

069500은 시장 ETF 대용지표 예시이며 투자 추천이나 코스닥 종목용 적합성 검증이 아닙니다.
실제 종목별 시장에 맞는 대용지표/지수를 분리해야 합니다. 현재 엔진은 한번에 벤치마크 하나만 지원합니다.
수집 반환기간·최대 보관기간은 API에 의해 제한되므로 2020년까지 조회된다고 보장하지 않습니다.
실제 2020~2026 단타 검증은 증권사 보유 이력 또는 별도 분봉 데이터 제공처 확보가 필요합니다.

## 비용과 체결 해석
기본 매매수수료 편도 0.015%, 매도세 0.20%, 슬리피지 편도 0.10%는 **검증용 가정**입니다.
현재 법정 세율·계좌 수수료를 의미하지 않습니다. config.json을 실제 거래일·계좌에 맞게 변경하세요.
연도별 세율 변경 자동 적용은 없으므로 기간별 분리 또는 확장이 필요합니다.
다음 봉 시가 체결은 OHLC 모델입니다. 호가단위, 실제 스프레드, 가격제한폭, VI, 미체결, 부분체결을 재현하지 못합니다.
일 손실 검사는 봉 종료에 수행하므로 봉 안 급락은 늦게 감지될 수 있습니다.

## 실제 자동주문 연결에 남은 구현
이 패키지는 주문을 증권사에 보내지 않습니다. paper.py는 역사적 자동 리플레이이며 실시간 모의투자 주문도 아닙니다.
실시간 운용에는 다음을 추가하고 키움 모의계좌에서 확인해야 합니다.
1. 완성봉 수신/장시간 동기화와 재연결, 일봉 유니버스 자동 갱신.
2. 잔고·현금·미체결 조회 후 신호별 주문상태 저장.
3. 지정가 주문, 취소·정정, 부분체결 처리 및 브로커 체결 기준 위험 재계산.
4. 재시작시 계좌와 로컬 장부 동기화 및 중복주문 방지.
5. VI/거래정지/호가/시장상태 확인과 손절·마감 청산 실패 대응.
6. 모의계좌와 백테스트 차이를 측정한 뒤 별도 실전 활성화.
