# GitHub Backtrader 전략 연구 v5

기존 우수 후보·신규 모멘텀/추세·현금 비중 보완안을 **같은 공개 주문 엔진**으로 비교한다. 실제 설치·사용 엔진은 https://github.com/mementum/backtrader 의 1.9.78.123이다. 기존 V8 목표 비중 계산 함수를 직접 재사용한다. `RESULT_KO.md`는 결과와 모든 제약, `comparison.csv`는 전체 비교, `details/`는 자산·입금·체결 원장이다.

## 한 번 실행

저장소 루트에서 실행한다. 데이터 다운로드 없이 포함된 스냅샷을 사용한다.

```bash
python -m pip install -r research/github_lab_v5/requirements.txt
python -m unittest discover -s research/github_lab_v5 -p 'test_*.py' -v
python research/github_lab_v5/run_all.py
python research/github_lab_v5/followup.py
python research/github_lab_v5/report.py
python research/github_lab_v5/plot.py
```

코딩 없이 결과를 보려면 해당 GitHub Actions 실행에서 `github-backtrader-v5-reproducible` 아티팩트를 다운로드한다. 실행 요약에도 보고서가 표시된다. PR 검토용 브랜치에 보관하며 실거래 설정을 변경하지 않는다.

## 비교 범위

- S&P500, 나스닥100, KOSPI200을 따로 평가.
- HOLD / 실제2배HOLD / 75:25 고정 혼합을 비교군으로 사용.
- 기존: MA200±1% 3일 확인, 변동성20% 목표, 모멘텀60일/20일 돌파의 종가 청산 변형, 국내V8의 HYST45 목표 비중 이식.
- 신규: 이동평균 추세 투표, 최근1개월을 제외한12개월 모멘텀, 지수+주식 코어,55일 돌파 코어,세 후보 앙상블.
- 비용1/2배, 일시금/같은월납입, 선택 후보의 체결1일 추가지연, 국내 선택후보와 비교군의 대체가격자료.
- 개발2018–2021에서 최악 비용/납입 Calmar가 최고인 모델을 선택. 이미 반복 연구한 역사자료라 검증/최종평가도 재사용 평가임을 명시.
- 연속운용의 부분기간 성과, 최초금액과월납입은 보고서 참조. 이전 연구와 시작금/현금흐름/위험·체결규칙이 달라 동일 실적으로 합치지 않는다.

## 사후 탐색 구분

`followup.py`는 모든 후보 중 재사용 검증/최종평가 × 두 비용 × 두 납입의 8조건에서 지수보다 수익률·낙폭이 함께 개선된 후보를 기계적으로 골라 추가 지연을 시험한다. 개발기간의 선택 모델은 바꾸지 않는다. 평가 결과를 보고 골랐다는 점을 `POST_HOC`로 표시한다. 잘 나온 결과도 미사용 미래 검증으로 부르지 않는다.

## 자료와 검증

미국 20개·국내10개 생존 대형주와 실제 ETF 스냅샷이다. 미국은 기존 Yahoo 조정가격, 국내 주 결과는 Naver **배당 미포함 가격**, 국내 대조는 Yahoo 조정가격이다. 공급원뿐 아니라 수익률 기준도 바뀌는 민감도 검사다. 전체 상장종목의 생존편향 없는 검증이나 AQR 지수 복제는 아니다.

`prepare_data.py`는 과거 연구 입력을 복사하고 국내 Naver 원자료를 받는 별도 준비 코드다. 기존 연구 파일이 없는 새 체크아웃에서는 이 다운로드 명령을 재실행하지 말고 포함된 `input/`을 쓴다. 포함 스냅샷이 오프라인 재현 기준이며 입력파일·원문 해시는 manifest에 있다.

Backtrader와 별도 원장을 모든 실행의 일별 자산금액으로 비교한다. 신호는 이전 완료 종가, 수량만 당일 시가로 결정한다. 실제 시가 확인 후 같은 시가 체결은 보장되지 않는다. 월납입은 시가 평가액으로 펀드 단위를 발행해 입금 영향과 수익을 구분한다. 정수 실주식 대신 조정가격 소수 단위다. 비용은 매수/매도 합산 비용으로 차감하고 현금이 부족한 매수는 줄인다. 평가 마지막 날 강제청산 비용은 넣지 않는다.

실시간 시세·증권사 키·실제 주문 전송은 없다. 연구 게이트를 통과해도 미래 수익은 보장되지 않으며, 독립 모의운용이 필요하다. 단타는 직전 PR#4에 별도 보관되어 있고 이번 연구는 일봉 비교에 집중한다.
