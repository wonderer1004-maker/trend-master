# 지수 보유·정기매수를 넘는 전략 연구 V3

개별종목 없이 코스피200·코스닥150·S&P500·나스닥100만 비교합니다.
15개 고정 능동 규칙과 4개 기준선(1배 보유, 실제2배 보유, 고정1.25/1.5배 혼합)을 모두 공개합니다.
레버리지 없는 대안은 UNLEV로 표시합니다. 실제 2배 ETF를 포함한 전략의 고수익은 위험 노출 효과일 수 있습니다.
ETF 실거래 조정 OHLC를 사용하며 지수 일수익률을 단순히 두 배 해 만든 가상 가격을 사용하지 않습니다.

## 현금흐름

- LUMP: 최초 1,000만원(미국 USD10,000), 이후 납입 없음.
- DCA: 최초 별도 일시금 없이 매월 첫 거래일 100만원(미국 USD1,000).
- 같은 납입 방식의 모든 전략은 동일한 날짜와 금액으로 입금합니다.
- 정기매수 기준선은 매월 납입금을 지수 ETF로 즉시 매수하고 기존 수량을 유지합니다.
- 신호는 전일 종가까지의 정보만 사용하며 다음 시가에 체결합니다. 2거래일 지연도 시험합니다.
- 자금은 시가에 입금하며 입금 직전 시가 순자산으로 펀드 단위를 발행합니다.
- TWR 단위가격 최대낙폭은 입금에 의한 착시를 제거합니다. 적립식 수익률은 날짜별 XIRR입니다.

## 비교·선택

코스피200·미국: 2012년부터, 코스닥150: 실제 ETF 상장 후 충분한 준비 기간이 있는 2017년부터입니다.
개발·검증·후속·최근 구간을 별도로 계산합니다. 공통/지수별 모델은 개발기간의 최악 초과 XIRR로 선택합니다.
검증·후속 기간을 사용해 규칙이나 가중치를 다시 맞추지 않습니다. 이미 여러 차례 본 역사 자료이므로 독립적인 실시간 검증은 아닙니다.
시작 연도 검사는 중첩되어 독립적인 표본이 아닙니다.

```bash
pip install pandas==2.2.3 numpy==2.3.5
python -m unittest discover -s research/index_challenge_v3 -p 'test_*.py' -v
python research/index_challenge_v3/run.py
```

입력 .csv.gz와 provenance.json이 재현 기준이며 실행 때 압축 해제한 CSV의 해시를 검사합니다.
일별 자산·단위가격·납입금·주문 내역은 Actions artifact에 있습니다.
미국 달러 수익률은 환율·개인 양도세를 제외합니다. 국내 ETF 개인 과세도 제외합니다.
거래비용은 기본/2배를 시험하고, 실제 ETF 비용과 금융조달 효과는 가격에 이미 포함되므로 이중 차감하지 않습니다.
일부 Yahoo 한국 가격 누락과 공통 날짜 사용 한계를 calendar_audit.json에 공개합니다.
실주문·기존 웹앱 설정·기본 브랜치를 변경하지 않습니다.

## 2차 가설: 두 지수 교체

1차 결과를 본 뒤 6개 월간 지수교체 규칙과 두 지수 각각 보유 기준선(640회)을 추가했습니다.
국내 코스피200/코스닥150은 2017년부터, 미국 SPY/QQQ는 2012년부터 같은 기간으로 비교합니다.
모멘텀6개월/12개월/혼합, 200일선 자격조건, 목표 노출1/1.25/1.5를 사용합니다.
이는 1차 결과 후의 탐색 단계이며 신규 독립검증으로 주장하지 않습니다. 두 단계 총 4288회입니다.
