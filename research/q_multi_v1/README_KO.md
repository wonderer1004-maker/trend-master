# Q-MULTI V1 검증 범위

이 폴더는 대회 수상자의 공개되지 않은 전략을 복제하지 않습니다.
설계 원안은 모멘텀 40%, 눌림 20%, 재무품질 40%의 독자 연구 가설입니다.

## 현재 가능한 검증

기존 저장소의 10개 생존 대형주와 KODEX200 가격 스냅샷을 사용하는 **가격 부분시험**입니다.
재무 신호가 없으므로 모멘텀 2/3, 눌림 1/3으로 재배분한 별도 변형입니다.
이 결과를 원안 전체의 백테스트 성과로 해석하면 안 됩니다.
시장 필터는 코스피 대신 KODEX200이고, 09:05 대신 다음 거래일 시가를 사용합니다.
원본 간 날짜 불일치는 공통 거래일만 남기며 `calendar_audit.json`에 제외 날짜를 공개합니다.
실제 종가/거래량 및 당시 상태가 아닌 조정 OHLC/거래량으로 유동성·가격 필터를 근사합니다.

## 실행

저장소 루트에서:

```bash
python -m unittest discover -s research/q_multi_v1 -p 'test_*.py' -v
python research/q_multi_v1/backtest.py
```

Actions의 `Q-MULTI V1 price-only pilot (full model blocked)`도 동일한 스냅샷을 재현합니다.
결과는 `reports/q_multi_v1/` 및 Actions artifact로 저장됩니다. 기존 전략·주문·웹앱을 변경하지 않습니다.

## 전체 전략이 차단된 이유

다음 데이터를 확보하지 못해 전체 전략 성과를 산출하지 않습니다.

- 공시 공개 시점이 포함된 과거 ROE, 영업현금흐름, 자산, 영업이익.
- 당시 상장·상장폐지·거래정지·관리/위험종목과 업종 이력.
- 실제 거래대금과 원주가, 코스피 지수, 분봉/미체결 자료.

수수료와 세금은 날짜별 실제 요율이 아닌 고정 가정이며, 원본 가격의 정확성을 독립적으로 재검증하지 않았습니다.
이미 사용한 과거 기간을 다시 시험하므로 진정한 표본 외 검증은 아닙니다.
손절도 다음 거래일에 체결하므로 12% 손실을 보장하는 규칙이 아닙니다.
