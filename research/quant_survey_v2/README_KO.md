# 공개 퀀트 연구 비교 V2

22개 원자료 항목을 조사해 14개 매수 전용 후보와 지수/동일비중 기준선을 비교합니다.
논문 원형의 선물·공매도·레버리지 전략 수익률을 복제했다고 주장하지 않습니다.
조사 출처와 적용 차이는 sources.json, 고정 매매 규칙은 engine.py의 RULES에 공개합니다.

미국: SPY, QQQ, IWM, EFA, EEM, IEF, TLT, GLD, DBC, VNQ, SHY.
국내: KODEX200과 기존 10개 생존 대형주. 국내 전 종목 검증이 아닙니다.
시가/종가 데이터는 2026-10-17에 Yahoo에서 수집했으며 2026-10-16까지입니다.
미국 2010~현재, 국내 2020~현재 외에 개발/후속 구간을 별도로 시험합니다.
입력은 CSV를 무손실 압축한 .csv.gz이며 압축 해제한 원본 SHA256을 실행 때 확인합니다.
원본 제공자의 국내 일부 날짜 누락은 calendar_audit.json에 공개합니다.

```bash
pip install pandas==2.2.3 numpy==2.3.5
python -m unittest discover -s research/quant_survey_v2 -p 'test_*.py' -v
python research/quant_survey_v2/run.py
```

결과는 reports/quant_survey_v2/에 생성됩니다.
일별 자산·연도별 수익률·거래내역은 GitHub Actions artifact에서 받을 수 있습니다.
재수집하려면 `python research/quant_survey_v2/download.py`를 실행합니다.
재수집 후 조정계수 변경 등으로 결과가 바뀔 수 있으므로 기존 압축 입력과 provenance.json이 재현 기준입니다.

개발기간에만 기반한 고정 선택 규칙을 사용하고, 전체기간 사후 최고값과 구분합니다.
564개 경우(미국5구간×18설정×비용2×지연2 + 국내3구간×17설정×비용2×지연2)를 전부 공개합니다.
추가로 28개 동일 위험자산 비중 대조군을 계산합니다. 동일 비중은 동일 변동성·베타를 뜻하지 않습니다.

모든 결과는 개인 세금 전·미국 환율 제외·고정 수수료/매도세 가정·소수 조정 단위 연구입니다.
과거 수익은 미래 수익 보장이 아니며, 생존/대상 선택 편향과 다중시험이 남습니다.
가치·품질·페어·장중 모멘텀 등 데이터가 부족한 전략은 성과를 만들지 않았습니다.
실제 자동매매 주문이나 기존 기본 브랜치의 전략 설정을 변경하지 않습니다.
