# TF-Blend / 120일 돌파 연구실

웹앱: https://wonderer1004-maker.github.io/trend-master/trend-following/

국내는 60/20 돌파, 120/60 돌파, SMA50/200 상태를 각 1/3 결합합니다. 미국은 120/60 돌파입니다. 일봉 확정 이후 다음 거래일 모델 목표를 보여 주며 **실제 주문·증권사 연결·푸시 전송은 하지 않습니다**.

## 사용
1. 국내/미국을 선택하고 그 매매계좌의 평가금액을 입력합니다. 국내는 원, 미국은 달러입니다. 자동 환전하지 않습니다.
2. 데이터 기준일과 다음 거래일을 확인합니다.
3. 상태 변화, 목표비중, 다음 진입·이탈 가격을 확인합니다. 수량은 목표 보유수량이며 추가 매수량이 아닙니다. 실제 보유 수량을 조회하지 않습니다.
4. 고정 연구 결과에서 편도 0.1%/0.5%를 바꿔 비교합니다. 테이블은 누적수익순이며 추천순위가 아닙니다.

금액은 localStorage에만 저장됩니다. 기기 간 동기화하지 않으며 코드나 서버로 전송하지 않습니다. 기본 1,000만원/1만 달러는 계산 예시입니다.

## 신호와 데이터
`publish.py`: 국내 Naver 4,000일 OHLCV, 미국 Yahoo 1999년 이후 OHLCV와 수정종가를 받습니다. 미국은 수정종가/종가 비율로 배당 반영을 근사하고, 화면의 기준선은 최근 원래 가격 단위로 환산합니다. 국내 분배금은 제외합니다. 미국 대상은 SPY/IWM/XLK/XLF/XLE/XLV, 국내는 069500/091160/139260/091170/102970/091180입니다.

상태는 국내 2015년, 미국 2002년 시작 상태 현금에서 재생합니다. 과거 기업행동 자료 수정 시 상태가 달라질 수 있습니다. 휴장일과 마감 시각은 exchange_calendars의 XKRX/XNYS를 쓰고 마감 20분 이후 봉만 허용합니다. 비공식 데이터 지연, 임시휴장, 달력 변경에는 별도 확인이 필요합니다.

진입은 종가가 당일을 제외한 과거 최고가를 **초과**, 이탈은 과거 최저가 **미만**입니다. 화면의 다음 기준선은 최신 확정 봉을 포함합니다. 등호는 유지. SMA는 단순평균입니다. 기본 목표한도는 60일 일수익률 표준편차(ddof=1) 연환산값의 역수 정규화 후 20% 상한. 현금은 재배분하지 않습니다. 주말/휴일 전 마지막 시장 세션에서 한도를 갱신하고, 주중 신호가 바뀌면 직전 한도로 목표를 바꿉니다. 실제 투자비중은 가격 변화로 목표에서 벗어날 수 있습니다.

Naver 091160의 작은 OHLC 범위 오류는 가격 대비 0.1% 미만일 때만 고가/저가 범위를 시가·종가까지 확장합니다. 큰 오류, 내부 결측, 날짜 불일치, 최신 확정 봉 부재는 해당 시장 갱신을 차단합니다. 기존 데이터는 남기되 status=error로 표시하고 웹에서 목표수량 계산을 막습니다. 마지막 갱신 확인이 72시간을 넘겨도 차단합니다. 휴일에는 보수적으로 차단될 수 있습니다. 이 검증이 KRX 공식 대조를 대체하지 않습니다.

## 갱신·게시
기존 `.github/workflows/domestic-yahoo-pages.yml`에 통합했습니다. 평일 한국시간 16:20·17:20 및 UTC 22:30(한국시간 다음 날 07:30)에 갱신과 Pages 게시를 시도합니다. Actions는 지연될 수 있습니다. 화면 새로고침은 게시된 JSON만 읽습니다. 워크플로의 새 자료는 배포 산출물에 포함되며 저장소에 매번 커밋하지 않습니다. 저장소의 초기 JSON은 설치 당시 스냅샷입니다. 기존 국내 알림 수집이 실패하면 전체 배포가 실패할 수 있으며 마지막 성공 페이지가 유지됩니다.

```bash
pip install -r trend_following/requirements.txt
python trend_following/publish.py
python -m unittest discover -s trend_following -p 'test_*.py' -v
node trend_following/test_ui.mjs
```

Pages 설정이 이미 GitHub Actions이면 기존 워크플로가 사이트 전체를 게시합니다. 설정이 안 된 경우 Settings → Pages → Source: GitHub Actions가 필요합니다.

## 백테스트 재실행
```bash
python trend_following/run_backtest.py --market US --start 2002-01-01 --end 2026-10-13
python trend_following/run_backtest.py --market KR --start 2015-01-01 --end 2026-10-13
```
종료일에는 확정 거래일을 입력하세요. 새 공급자료로 재계산하므로 고정 보고서와 미세하게 다를 수 있습니다. 결과는 `reports/tf_following`에 생성됩니다. 웹의 고정 연구 결과를 자동으로 덮어쓰지 않습니다. `engine.py`는 V2 계산 엔진이며 직접 main으로 실행하지 않고 위 runner를 사용합니다. `protocol.json`은 기존 공통 엔진 설정으로 과거 연구 대상 목록도 포함되어 있으며 runner의 대상은 publish.py의 MARKETS입니다.

연구 보고서: [2차 연구](../docs/trend-following/REPORT_KO.md). 보고서의 전체 원자료 ZIP은 기존 대화 첨부를 참고하세요. 웹에는 전체 거래자료 대신 고정 비교 요약을 게시했습니다.

과거 성과는 가상 계산입니다. 세금·환전·현금이자·정수 수량·실제 체결을 완전히 반영하지 않았고, 생존편향과 과거 구간 재사용이 남아 있습니다. 장기 적립 계좌와 별도 연구용으로 구분하세요.
